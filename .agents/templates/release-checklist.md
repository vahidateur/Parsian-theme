## Gates

- [ ] Requirements and acceptance criteria approved.
- [ ] Architecture contracts and ADRs approved.
- [ ] Implementation scoped and complete.
- [ ] Independent code review passed with no blockers.
- [ ] QA evidence recorded on the candidate SHA.
- [ ] Security findings dispositioned; no unaccepted `HIGH`/`BLOCKER`.
- [ ] Integration branch conflict-free.
- [ ] Required CI checks passed on the candidate SHA.
- [ ] Artifacts built from a clean checkout.
- [ ] Artifacts inspected: no tests, dev dependencies, databases, backups, or secrets.
- [ ] Checksums recorded.
- [ ] Changelog and release notes prepared.
- [ ] Rollback plan documented.
- [ ] Previous release assets preserved.
- [ ] Human owner approved tag/release/deployment.
