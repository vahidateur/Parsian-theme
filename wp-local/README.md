# وردپرس محلی — آکادمی موسیقی پارسیان

محیط توسعهٔ کامل و بدون نیاز به `sudo`، با MySQL اختصاصی. همهٔ سرویس‌ها در فضای کاربری اجرا می‌شوند و به سرویس‌های سیستمی دست نمی‌زنند.

## نسخه‌ها

| جزء | نسخه |
|---|---|
| WordPress | 7.1.4 (آخرین نسخه) |
| PHP | 8.5.4 + GD |
| MySQL | 8.4.11 LTS |
| پوسته | parsian-music 1.6.0 (همین پوشهٔ پروژه) |
| زبان | فارسی (fa_IR) |

## آدرس‌ها و ورود

- سایت: <http://127.0.0.1:8081>
- پیشخوان: <http://127.0.0.1:8081/wp-admin/>
- نام کاربری: `admin`
- رمز عبور: `ParsianAdmin!2026`

> پورت 8081 انتخاب شده تا با پروژهٔ Laravel (اسکریپت `parsian-dev` که از 8080 استفاده می‌کند) تداخل نداشته باشد.

## پنل تنظیمات قالب

- از منوی **پارسیان** در پیشخوان یا مستقیم از <http://127.0.0.1:8081/wp-admin/admin.php?page=pm-settings>
- تب‌ها: برند و تماس، صفحه اصلی، سوالات متداول، اساتید، فوتر، ورود و پیشخوان، دستیار هوشمند، اعلان‌ها و پیام‌رسان‌ها، فرم‌ها، ابزارها
- ویرایش هیرو، ویژگی‌ها، دپارتمان‌ها، آمار، مسترکلاس، نظر هنرجو، سوالات متداول، صفحهٔ ورود و پیام پیشخوان
- فیلدهای تکرارشونده با افزودن/حذف/جابه‌جایی و انتخاب‌گر تصویر
- بازگشت به پیش‌فرض و ساخت محتوای نمایشی در تب «ابزارها»

## دستیار هوشمند

- آیکون شناور سمت راست پایین در سایت نمایش داده می‌شود.
- تنظیمات: <http://127.0.0.1:8081/wp-admin/admin.php?page=pm-settings> → تب **دستیار هوشمند**
- فیلدها: فعال/غیرفعال، آدرس API، کلید API، مدل، دستور سیستم و پیام خوش‌آمد
- ایندکس سایت: **ابزارها ← ایندکس دستیار هوشمند ← بازسازی ایندکس سایت**
- فایل ایندکس: `site/wp-content/uploads/pm-ai-index.json`
- دستیار در زمان پاسخ‌دهی فقط این فایل را می‌خواند و به دیتابیس کوئری نمی‌زند.
- برای تست بدون API واقعی، اتصال در پنل خالی می‌ماند و پیام «تنظیمات کامل نشده» برمی‌گردد.

## اعلان‌ها (بله/روبیکا)

- تنظیمات: **پارسیان ← تنظیمات ← اعلان‌ها و پیام‌رسان‌ها** + صفحهٔ **پارسیان ← اعلان‌ها**
- پلتفرم پیش‌فرض `disabled` است؛ بدون Chat ID پیامی ارسال نمی‌شود. شمارهٔ موبایل فقط مرجع است.
- توکن‌ها `secret` هستند و هرگز در HTML/REST/لاگ چاپ نمی‌شوند.
- جدول `wp_pm_notifications`؛ صف WP-Cron + تلاش مجدد backoff، جلوگیری از تکراری، ایمیل پشتیبان اختیاری.
- تست واقعی بله/روبیکا نیازمند توکن و Chat ID واقعی + اینترنت است (در لوکال با mock تأیید شد).

## دانش دستیار

- مدیریت: **پارسیان ← دانش دستیار**؛ بازخوردها `pending` می‌مانند تا تأیید شوند.
- فایل‌ها: `site/wp-content/uploads/pm-ai-index.json` و `pm-ai-approved.json`
- تست دود: `cd wp-local && ./wp eval-file tests/pm-1.6.0-smoke.php` (۱۵ تست، همه سبز)

## فرم مشاوره و فوتر

- تنظیمات فرم: **پارسیان ← فرم مشاوره** (متن‌ها، فیلدها، گزینه‌ها، تب تلفنی و شمارهٔ تماس)
- تب تلفنی فیلدها را پنهان می‌کند و لینک `tel:` نمایش می‌دهد.
- ویجت‌ها: **نمایش ← ویجت‌ها** → «فوتر پنل پایینی» و «سوالات متداول (ویجت)»
- مسیریابی: **پارسیان ← برند و تماس** → لینک نقشه یا مختصات `lat/lng` (نشان)؛ بدون مختصات، جستجوی گوگل‌مپ ساخته می‌شود.

## سرویس‌ها

دو سرویس systemd کاربری ساخته شده است:

```bash
systemctl --user status parsian-mysql.service
systemctl --user status parsian-wp.service
```

یا با اسکریپت‌های همین پوشه:

```bash
./start.sh   # روشن کردن دیتابیس و وب‌سرور
./stop.sh    # خاموش کردن هر دو
```

سرویس‌ها با ورود کاربر به‌صورت خودکار فعال می‌شوند. لاگ‌ها:

```bash
journalctl --user -u parsian-mysql.service -f
journalctl --user -u parsian-wp.service -f
tail -f site/wp-content/debug.log
```

## دیتابیس

| مقدار | مقدار |
|---|---|
| Host | `127.0.0.1:3307` |
| Database | `parsian_wp` |
| User | `parsian` |
| Password | `Parsian_Local_2026!` |
| Socket | `mysql/run/mysqld.sock` |

اتصال مستقیم:

```bash
mysql -h 127.0.0.1 -P 3307 -u parsian -p'Parsian_Local_2026!' parsian_wp
```

> پورت 3307 است چون MySQL سیستمی روی 3306 و MariaDB پروژهٔ دیگر روی سوکت جداگانه اجرا می‌شود. هیچ‌کدام تغییر نکرده‌اند.

```
wp-local/
├── site/                 # نصب وردپرس
│   ├── wp-content/themes/parsian-music -> پوشهٔ اصلی پروژه
│   ├── router.php        # روتینگ پیوندهای یکتا برای وب‌سرور داخلی PHP
│   └── wp-config.php
├── mysql/                # نمونهٔ خصوصی MySQL (داده‌ها، سوکت، لاگ)

```

پوسته به‌صورت symlink وصل شده است؛ هر تغییری در `parsian-music/` بلافاصله روی سایت دیده می‌شود و نیازی به کپی مجدد نیست.

## انتقال به هاست اشتراکی

1. فایل `parsian-music.zip` را از صفحهٔ [Release نسخهٔ 1.6.0](https://github.com/vahidateur/Parsian-theme/releases/tag/v1.6.0) دانلود کنید و از پیشخوان وردپرس (نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته) نصب و فعال کنید.
2. برای محتوا، از همین محیط دامپ بگیرید:

```bash
./wp db export backups/for-hosting.sql
```

3. در `wp-config.php` هاست، مقادیر دیتابیس هاست را جایگزین کنید.
4. اگر هاست از MariaDB قدیمی استفاده می‌کند و ایمپورت دامپ خطا داد، ابتدا فقط پوسته را نصب کنید و محتوا را با افزونهٔ مهاجرت (مثل All-in-One WP Migration) منتقل کنید.

## عیب‌یابی

- **سایت بالا نمی‌آید:** `systemctl --user restart parsian-mysql parsian-wp`
- **خطای دیتابیس:** مطمئن شوید `parsian-mysql.service` فعال است و پورت 3307 گوش می‌دهد: `ss -tln | grep 3307`
- **تغییر رمز ادمین:** `./wp user update admin --user_pass='NewPassword'`
- **تغییر پورت:** پورت را در `~/.local/bin/parsian-wp-server` عوض کنید، سپس:
  `./wp option update home http://127.0.0.1:NEW_PORT` و `./wp option update siteurl http://127.0.0.1:NEW_PORT` و سرویس را restart کنید.
- **پاک کردن کامل:** ابتدا `./stop.sh`، سپس پوشهٔ `wp-local` را حذف کنید و یونیت‌های `~/.config/systemd/user/parsian-*.service` را هم بردارید.

## نکتهٔ امنیتی

این محیط فقط روی `127.0.0.1` گوش می‌دهد و از اینترنت قابل دسترسی نیست. رمزهای داخل این فایل فقط برای توسعهٔ محلی هستند و نباید روی هاست واقعی استفاده شوند.
