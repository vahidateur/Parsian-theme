# قالب وردپرس کنسرواتوار موسیقی پارسیان

نصب: پوشه `parsian-music` را (یا فایل zip آن را) از مسیر «نمایش ← پوسته‌ها ← افزودن» نصب و فعال کنید.

- صفحه اصلی: `front-page.php` (در تنظیمات ← خواندن، «صفحه اصلی» را روی «آخرین نوشته‌ها» یا هر صفحه دلخواه بگذارید؛ front-page همیشه اولویت دارد)
- منوها: «نمایش ← منوها» ← منوی اصلی و منوی فوتر
- لوگو: «نمایش ← سفارشی‌سازی ← هویت سایت»
- فرم رزرو مشاوره به ایمیل مدیر سایت ارسال می‌شود.
- محتوای کارت‌ها (دپارتمان‌ها، اساتید، سوالات) در آرایه‌های بالای `front-page.php` قابل ویرایش است.
