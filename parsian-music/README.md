# قالب وردپرس آکادمی موسیقی پارسیان

قالب اختصاصی، فارسی و راست‌چین برای **آکادمی موسیقی پارسیان** با زبان طراحی تیره و طلایی. این قالب از ادغام «صفحهٔ اصلی وردپرسی» و «صفحهٔ پروفایل استاد» ساخته شده است.

## پیش‌نیازهای پلتفرم

| جزء | حداقل | پیشنهادی / آزمایش‌شده |
|---|---|---|
| WordPress | 7.1 | 7.1.4 |
| PHP | 8.4.27 | 8.5.12 |
| MySQL | 8.4 LTS | 8.4.13 |
| MariaDB | 12.3 LTS | 12.3.3 (اصلی) / 11.8.9 (سازگاری قبلی) |
| WP-CLI | 2.12.0 | 2.12.0 |
| Node.js / npm (فقط تست JS) | 26.13.0 / 12.2.2 | همان |

افزونه‌های PHP موردنیاز: `curl`، `json`، `mbstring`، `mysqli` یا `pdo_mysql`،
`openssl`، `zip`، `xml` و `gd` یا `imagick`؛ `opcache` توصیه می‌شود.
Composer لازم نیست. جزئیات و منابع نسخه‌ها در `docs/PLATFORM-COMPATIBILITY.md`.

## ویژگی‌ها

- صفحهٔ اصلی داشبوردی سه‌ستونه با الهام از صفحهٔ استاد
- پروفایل اختصاصی هر استاد با چیدمان سه‌ستونه، مقایسهٔ قبل/بعد، دستاوردها، ویدئو، نمونهٔ صوتی و فرم رزرو
- آرشیو اساتید با فیلتر دپارتمان و صفحهٔ اختصاصی هر استاد
- نوع محتوای سفارشی `pm_teacher` و تاکسونومی `pm_department`
- فرم مشاوره با nonce، اعتبارسنجی سرور، نرمال‌سازی موبایل ایرانی، rate-limit، جلوگیری از تکراری، شناسهٔ یکتا، ذخیره در پیشخوان و ارسال از درگاه بله/روبیکا (ایمیل مستقیم حذف شده؛ ایمیل فقط پشتیبان است)
- نوع محتوای داخلی `pm_booking` برای نگهداری درخواست‌های مشاوره
- قالب‌های صفحه، نوشته، آرشیو، جستجو، ۴۰۴ و دیدگاه‌ها
- قالب «تمام عرض» برای صفحه‌سازهایی مثل Elementor
- اسپرایت SVG یکپارچه، RTL کامل و ریسپانسیو
- تنظیمات برند، تماس، شبکه‌های اجتماعی و متن هیرو در سفارشی‌ساز وردپرس
- پنل تنظیمات گرافیکی و مدرن «پارسیان» با ۶ تب، فیلدهای تکرارشونده و انتخاب‌گر تصویر
- صفحهٔ ورود اختصاصی با پس‌زمینهٔ تصویری، کارت شیشه‌ای و هماهنگ با هویت سایت
- پیشخوان مدیریت‌شده با کارت خوش‌آمد، آمار، آخرین درخواست‌های مشاوره و میان‌برها

- لایهٔ طراحی مینیمال و آرام Apple-like با منحنی squircle، دکمههای مات و فلشهای تعاملی
- فوتر پنلی با تیتر، توضیح و دکمهٔ قابل ویرایش از پنل تنظیمات
- کارتهای اساتید بزرگتر با پرتره، نشان تخصص و دکمهٔ ورود تعاملی

## نصب

1. پوشهٔ `parsian-music` را در `wp-content/themes/` قرار دهید یا از فایل zip آن را از مسیر **نمایش ← پوسته‌ها ← افزودن** نصب کنید.
2. قالب را فعال کنید.
3. در اولین فعال‌سازی، ۶ استاد نمایشی و ۶ دپارتمان ساخته می‌شوند تا ظاهر سایت کامل باشد.
4. از **تنظیمات ← پیوندهای یکتا** یک بار ذخیره کنید (یا صفحه را رفرش کنید) تا آدرس اساتید ساخته شود.
5. از **نمایش ← منوها** منوی اصلی و فوتر را بسازید. تا قبل از ساخت منو، منوی پیش‌فرض با لینک‌های صفحهٔ اصلی نمایش داده می‌شود.

> نام استاد واقعی: **استاد محمدرضا کریمی** (مدیر مسئول و استاد ویولن). سایر اساتید با عنوان‌های «استاد پیانو»، «استاد موسیقی ایرانی» و... فقط محتوای نمایشی هستند و باید با اطلاعات واقعی جایگزین یا حذف شوند.

## پنل تنظیمات پارسیان

از منوی **پارسیان** در پیشخوان باز می‌شود. همهٔ گزینه‌ها در تب‌های زیر دسته‌بندی شده‌اند:

| تب | موارد قابل ویرایش |
|---|---|
| برند و تماس | نام برند، زیرعنوان لاتین، تلفن، ایمیل، آدرس، ایمیل دریافت درخواست و شبکه‌های اجتماعی |
| صفحه اصلی | هیرو، تصویر هیرو، برچسب‌ها، دکمه‌ها، نکات و اعداد، عنوان بخش‌ها، ویژگی‌ها، دپارتمان‌ها، آمار، مسترکلاس، قبل/بعد و نظر هنرجو |
| سوالات متداول | افزودن، حذف و ویرایش سوالات پرتکرار (یا اتصال ویجت) |
| اساتید | معرفی کوتاه آرشیو اساتید |
| فوتر | متن کوتاه و متن لینک پایین |
| ورود و پیشخوان | تصویر پس‌زمینه و پیام صفحهٔ ورود، عنوان و متن خوش‌آمد و اطلاعیهٔ پیشخوان |
| دستیار هوشمند | فعال/غیرفعال، آدرس API، کلید API، مدل، دستور سیستم، پیام خوش‌آمد، یادگیری از بازخورد |
| اعلان‌ها و پیام‌رسان‌ها | پلتفرم (غیرفعال/بله/روبیکا/هر دو)، توکن‌ها، Chat IDها، ایمیل پشتیبان، تلاش مجدد، تست اتصال |
| فرم‌ها | برچسب‌ها، placeholderها، فیلدهای اجباری، گزینه‌ها، عنوان و دکمهٔ فرم مشاوره + تب تلفنی |
| ابزارها | وضعیت سیستم، ساخت محتوای نمایشی و بازگشت به تنظیمات پیش‌فرض |

- فیلدهای تکرارشونده (ویژگی‌ها، دپارتمان‌ها، آمار، سوالات متداول) دکمهٔ افزودن، حذف و جابه‌جایی دارند.
- تصاویر از کتابخانهٔ رسانه انتخاب می‌شوند و پیش‌نمایش فوری دارند.
- تنظیمات در theme mods وردپرس ذخیره می‌شوند؛ بنابراین همچنان در **نمایش ← سفارشی‌سازی** هم در دسترس هستند.
- اگر همهٔ ردیف‌های یک بخش حذف شوند، مقادیر پیش‌فرض پوسته برمی‌گردند.

## اعلان‌ها و پیام‌رسان‌ها (۱.۶.۰)

- درگاه متمرکز اعلان در `inc/notifications.php` با جدول `wp_pm_notifications`؛ همهٔ فرم‌ها فقط همین درگاه را صدا می‌زنند.
- پلتفرم‌ها: غیرفعال / بله / روبیکا / هر دو. بدون Chat ID پیامی ارسال نمی‌شود؛ شمارهٔ موبایل فقط مرجع نمایشی است.
- آدرس‌های رسمی: بله `https://tapi.bale.ai/bot{token}/{method}` و روبیکا `https://botapi.rubika.ir/v3/{token}/{method}` (هر دو از تنظیمات قابل تغییرند).
- توکن‌ها با فیلد `secret` ذخیره می‌شوند؛ در صفحه، REST، HTML و لاگ هرگز چاپ نمی‌شوند و مقدار خالی در فرم یعنی «حفظ مقدار قبلی».
- صف ناهمگام با WP-Cron + پردازش فرصت‌طلب فرانت‌اند، تلاش مجدد با backoff نمایی، جلوگیری از تکراری (`submission_id` یکتا به‌صورت `PM-YYYYMMDD-XXXXXX`)، وضعیت ارسال، لاگ، تلاش مجدد دستی و تست اتصال.
- ایمیل پشتیبان اختیاری فقط وقتی ارسال می‌شود که همهٔ پیام‌رسان‌ها ناموفق باشند.
- مدیریت: **پارسیان ← اعلان‌ها** (آمار، فیلتر، جدول وضعیت، تست اتصال، دریافت Chat ID، پردازش صف، پاک‌سازی نگهداری).

## دانش دستیار و بازخورد (۱.۶.۰)

- جدول `wp_pm_ai_knowledge` + فایل `pm-ai-approved.json`؛ بازخورد مثبت/منفی ابتدا `pending` می‌ماند و فقط پس از تأیید مدیر وارد دانش می‌شود؛ جلوگیری از تکراری با hash.
- مدیریت: **پارسیان ← دانش دستیار** (جستجو، فیلتر وضعیت، افزودن/ویرایش/تأیید/رد/حذف، نسخه‌بندی، بازسازی دانش و ایندکس).
- ایندکس (`pm-ai-index.json`) از محتوای منتشرشده + دانش تأییدشده ساخته می‌شود، بدون تکراری و بدون کوئری دیتابیس در زمان پاسخ.
- دفاع تزریق پرامپت: الگوهای فارسی/انگلیسی، جداکنندهٔ `<untrusted_data>`، قوانین امنیتی در system prompt و redact خودکار توکن/کلید در پاسخ.

## صفحهٔ ورود و پیشخوان

- صفحهٔ ورود با پس‌زمینهٔ تصویری، کارت شیشه‌ای، فونت وزیرمتن و رنگ طلایی هماهنگ با سایت بازطراحی شده است. تصویر و پیام آن از تب **ورود و پیشخوان** قابل تغییر است.
- پیشخوان وردپرس شامل کارت خوش‌آمد پارسیان، آمار اساتید/درخواست‌ها/نوشته‌ها/برگه‌ها، آخرین درخواست‌های مشاوره و میان‌برهای مدیریتی است. ابزارک‌های پیش‌فرض و تبلیغاتی افزونه‌ها حذف شده‌اند.
- تعداد درخواست‌های مشاورهٔ خوانده‌نشده کنار منوی «درخواست‌ها» نمایش داده می‌شود.

## تصاویر

- تصویر استاد اصلی `teacher-karimi.webp` است و نوار بالای اسکرینشات مرجع از آن بریده شده است.
- پرترههای سایر اساتید نمایشی و تصاویر ویدئویی/قبل–بعد از فایلهای پاکسازیشدهٔ `conductor.jpg`، `student.jpg`، `hero.jpg`، `portrait-persian.webp`، `portrait-vocal.webp` و `portrait-theory.webp` استفاده میکنند تا متن و دکمهٔ پخش اسکرینشات مرجع در کارتها دیده نشود.
- برای جایگزینی با عکس واقعی، از **اساتید ← ویرایش استاد ← تصویر پرتره** یا تصویر شاخص استفاده کنید.
- تصاویر بخش‌های دیگر در `assets/images/` قرار دارند و با WebP/JPG بهینه شده‌اند.

## مدیریت اساتید

از پیشخوان **اساتید** را باز کنید. برای هر استاد این فیلدها وجود دارد:

| فیلد | کاربرد |
|---|---|
| نام انگلیسی | نمایش زیر نام فارسی در پروفایل |
| سمت / عنوان | مثلاً «مدیر مسئول و استاد ویولن» |
| ساز / تخصص | نمایش در برچسب‌های پروفایل |
| مدرک تحصیلی | نمایش در کارت و پروفایل |
| سابقه | نمایش در برچسب‌های پروفایل |
| روزهای حضور | با کاما جدا شود؛ در نوار روی تصویر نمایش داده می‌شود |
| تصویر پرتره | آدرس تصویر یا انتخاب از کتابخانهٔ رسانه |
| لینک ویدئوی معرفی | آدرس YouTube/Vimeo/MP4 |
| لینک نمونهٔ صوتی | آدرس MP3/OGG |
| بیوگرافی کوتاه | متن معرفی در پروفایل |
| آمار | هر خط: `مقدار|برچسب` |
| دستاوردها | هر خط: `مقدار|برچسب` |
| ویدئوها | هر خط: `عنوان|مدت|لینک|تصویر` |
| نظر هنرجو | نام، عنوان، تصویر و متن نظر |
| تصویر قبل / بعد | برای کارت مقایسهٔ پیشرفت |

> اگر فیلد «بیوگرافی کوتاه» خالی باشد، از چکیده یا متن ویرایشگر استفاده می‌شود. برای جلوگیری از سردرگمی، متن اصلی معرفی را در همان فیلد بیوگرافی کوتاه بنویسید.

### دپارتمان‌ها

دپارتمان‌ها در **اساتید ← دپارتمان‌ها** قابل مدیریت هستند. اسلاگ‌های پیشنهادی:

`strings`، `piano`، `persian`، `theory`، `vocal`، `kids`

فیلترهای صفحهٔ اصلی و آرشیو بر اساس همین اسلاگ‌ها کار می‌کنند.

## صفحهٔ اصلی

بخش‌های صفحهٔ اصلی در `front-page.php` و `template-parts/sections/` قرار دارند. همهٔ متن‌ها، تصاویر، ویژگی‌ها، دپارتمان‌ها، آمار، مسترکلاس و نظر هنرجو از **پارسیان ← صفحه اصلی** و سوالات متداول از تب **پارسیان ← سوالات متداول** قابل ویرایش هستند.

مقادیر پیش‌فرض همچنان در `inc/demo-content.php` نگهداری می‌شوند و اگر گزینه‌ای در پنل ذخیره نشده باشد، از همان‌ها استفاده می‌شود. برای ویرایش گروهی یا کدنویسی، می‌توانید همان فایل را تغییر دهید.


## زبان طراحی

لایهٔ `assets/css/refine.css` بر اساس مرجع طراحی بازنویسی شده است: پس‌زمینهٔ تقریباً مشکی و آرام، هدر شیشه‌ای، چیپ‌های فیلتر، کارت‌های افقی اساتید با پرترهٔ سیاه‌وسفید، بنر موسیقی کودک و پنل سه‌ستونهٔ تماس. منحنی کارت‌ها squircle است، دکمه‌ها پیل‌شکل و مات هستند و چیدمان از ۳۶۰ تا ۱۴۴۰ پیکسل تست شده است.

## فرم مشاوره

فرم‌ها به `admin-post.php` ارسال می‌شوند و شامل این موارد هستند:

- nonce وردپرس
- هانی‌پات ساده برای جلوگیری از اسپم
- اعتبارسنجی سمت سرور (نام، موبایل، ساز)
- ذخیرهٔ درخواست در **درخواست‌ها** در پیشخوان
- ارسال ایمیل به آدرس مدیر یا ایمیل تعیین‌شده در سفارشی‌ساز
- بازگشت به همان صفحه با پیام موفقیت/خطا

ایمیل دریافت درخواست‌ها را در **پارسیان ← برند و تماس ← ایمیل دریافت درخواست‌ها** تنظیم کنید. اگر خالی باشد، ایمیل مدیر سایت استفاده می‌شود.

### تنظیمات فرم در پنل

تب **پارسیان ← فرم مشاوره** کنترل کامل فرم را در اختیار می‌گذارد:

- عنوان، توضیح و متن دکمهٔ ارسال
- برچسب، متن جای‌نگهدار و اجباری‌بودن نام، موبایل و ساز
- گزینه‌های ساز و موضوع مشاوره
- نمایش/مخفی‌کردن فیلد توضیحات
- فعال/غیرفعال‌کردن تب **مشاوره تلفنی**
- شمارهٔ تماس، متن راهنما و ساعات پاسخ‌گویی

با انتخاب تب «مشاوره تلفنی»، فیلدهای فرم پنهان می‌شوند و شمارهٔ تماس به‌صورت لینک `tel:` نمایش داده می‌شود تا کاربر مستقیم با گوشی خود تماس بگیرد.

## منوها و لوگو

- منوی اصلی: **نمایش ← منوها ← منوی اصلی**
- منوی فوتر: **نمایش ← منوها ← منوی فوتر**
- لوگو: **نمایش ← سفارشی‌سازی ← هویت سایت**
- در صورت نبود منو، منوی پیش‌فرض با لینک‌های `#courses`، `#teachers`، `#masterclass`، `#faq`، `#contact` نمایش داده می‌شود.

## سازگاری با افزونه‌ها

- **Elementor / صفحه‌سازها:** قالب صفحهٔ «تمام عرض (بدون کانتینر)» را انتخاب کنید. هدر و فوتر قالب حفظ می‌شوند.
- **ACF:** قالب به ACF وابسته نیست؛ اما در صورت فعال بودن، فیلدهایnative قالب بدون تداخل کار می‌کنند. در صورت نیاز می‌توان فیلدها را به ACF متصل کرد.
- **Contact Form 7 / WPForms / Fluent Forms:** می‌توانید شورت‌کد فرم را در محتوای صفحه قرار دهید؛ فرم اختصاصی قالب نیز مستقل کار می‌کند.
- **Rank Math / Yoast SEO:** قالب از `title-tag`، `wp_head` و `wp_footer` استاندارد استفاده می‌کند.
- **WooCommerce:** قالب به‌صورت پیش‌فرض فروشگاه ندارد؛ در صورت نیاز، قالب‌های WooCommerce باید جداگانه اضافه شوند.

> برای هم‌خوانی دقیق‌تر، لیست افزونه‌های مورد استفادهٔ خود را اعلام کنید تا بررسی و تنظیمات لازم انجام شود.

## دستیار هوشمند

- آیکون شناور در پایین سمت راست همهٔ صفحات سایت نمایش داده می‌شود و با کلیک، پنل چت باز می‌شود.
- تنظیمات آن در **پارسیان ← دستیار هوشمند** است: فعال/غیرفعال، آدرس API، کلید API، مدل، دستور سیستم و پیام خوش‌آمد.
- API باید سازگار با OpenAI Chat Completions باشد؛ نمونه: `https://api.openai.com/v1/chat/completions` و مدل `gpt-4o-mini`.
- کلید API فقط در پیشخوان نگهداری می‌شود و به مرورگر کاربران ارسال نمی‌شود.
- دستیار برای پاسخ‌دهی هیچ کوئری‌ای به دیتابیس نمی‌زند؛ فقط فایل ایندکس `wp-content/uploads/pm-ai-index.json` را می‌خواند.
- ساخت و بازسازی ایندکس از **پارسیان ← ابزارها ← ایندکس دستیار هوشمند** انجام می‌شود. بعد از تغییر محتوا یک بار آن را بازسازی کنید.
- در زمان پاسخ‌دهی، متن سوال با مدخل‌های مرتبط ایندکس تطبیق داده می‌شود و همان بخش‌ها به مدل داده می‌شود (رویکرد RAG، نه اتصال مستقیم به دیتابیس).
- محدودیت ۳۰ درخواست در ساعت برای هر IP و بررسی nonce برای جلوگیری از سوءاستفاده اعمال شده است.
- سوال‌های پیشنهادی، دانشنامهٔ دستیار و یادگیری از بازخورد کاربران از همان تب قابل مدیریت است.

## فوتر، ویجت و نقشه

- محتوای فوتر داخل ستون سوم پنل پایینی قرار گرفته و فوتر جداگانه در صفحه‌های اصلی حذف شده است.
- اندازهٔ متن برند، دسترسی سریع و اطلاعات تماس به حد استاندارد افزایش یافته است.
- دو ناحیهٔ ویجت اضافه شده است: **فوتر پنل پایینی** و **سوالات متداول (ویجت)**. اگر ویجت اضافه شود، جایگزین محتوای پیش‌فرض همان بخش می‌شود.
- دکمهٔ **مسیریابی تا آکادمی** از لینک دلخواه، مختصات `lat/lng` (لینک نشان) یا جستجوی آدرس گوگل‌مپ ساخته می‌شود.
- برای باز شدن مستقیم اپ نشان، مختصات آکادمی را در **برند و تماس** وارد کنید یا لینک آمادهٔ `nshn.ir` را در فیلد لینک نقشه بگذارید.


## افزونه‌های ضروری

این افزونه‌ها در محیط لوکال نصب و فعال شده‌اند. داخل فایل zip پوسته نیستند و روی هاست باید جداگانه نصب شوند:

| افزونه | کاربرد | نکته |
|---|---|---|
| Rank Math SEO | سئو، نقشهٔ سایت و متادیتا | ویزارد اولیه را کامل کنید |
| Wordfence Security | امنیت و فایروال | در حالت یادگیری شروع می‌کند |
| UpdraftPlus | پشتیبان‌گیری | یک زمان‌بندی و مقصد ذخیره انتخاب کنید |
| WP Super Cache | کش صفحات | در لوکال خاموش است؛ روی هاست فعال کنید |
| WP Mail SMTP | ارسال مطمئن ایمیل فرم‌ها | اطلاعات SMTP هاست را وارد کنید |
| WP-Parsidate | تاریخ شمسی و فارسی‌سازی | تنظیمات پیش‌فرض فعال است |

> برای محیط لوکال، کش عمداً فعال نشده تا تغییرات پوسته فوراً دیده شوند.

## تست محلی

در این پروژه یک محیط کامل وردپرس + MySQL در پوشهٔ `wp-local` آماده شده است:

```bash
cd wp-local
./start.sh
```

- سایت: `http://127.0.0.1:8081`
- پیشخوان: `http://127.0.0.1:8081/wp-admin/`
- راهنمای کامل: `wp-local/README.md`

اگر فقط می‌خواهید پوسته را سریع و بدون MySQL ببینید، WordPress Playground هم گزینهٔ جایگزین است:

```bash
npx @wp-playground/cli start --path=./parsian-music --port=9401
```

## نکات باقی‌مانده

- تصاویر واقعی اساتید را جایگزین تصاویر SVG نمایشی کنید.
- برای ویدئوها و نمونهٔ صوتی، لینک واقعی وارد کنید؛ تا زمانی که خالی باشند، دکمه‌ها پیام «به‌زودی» نشان می‌دهند.
- در صورت نیاز به فروش دوره، عضویت یا سیستم پرداخت، افزونهٔ مربوطه و قالب‌های آن باید اضافه شوند.
- برای صفحهٔ «درباره ما» و «ارتباط با ما» می‌توانید از قالب صفحهٔ معمولی یا Elementor استفاده کنید.
- ویزاردهای Rank Math، Wordfence، UpdraftPlus و WP Mail SMTP را روی هاست واقعی کامل کنید.
